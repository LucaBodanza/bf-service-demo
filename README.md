# BF Service — anteprima sito web

Anteprima navigabile del nuovo sito di **BF Service di Bodanza Francesco**
(office automation — assistenza, noleggio e vendita per l'ufficio).

🔗 **Anteprima online:** attiva GitHub Pages e l'indirizzo comparirà qui.

## A cosa serve

Serve a Luca, Giuseppe e papà per navigare il sito, vedere le criticità e
raccogliere le correzioni prima di costruire la versione definitiva su WordPress.

Non è il sito pubblico: è marcato `noindex`, quindi Google non lo indicizza e
non fa concorrenza al sito ufficiale.

## Come aggiornare

Sostituisci `index.html` con la versione nuova. GitHub Pages si aggiorna da solo
in un paio di minuti e **l'indirizzo non cambia mai**.
